\section{Selecci\'on de bibliotecas y primitivas}
\label{sec:primitivas}

La elecci\'on de herramientas criptogr\'aficas obedece a criterios de rigor
matem\'atico, seguridad frente a ataques de canal lateral y soporte de operaciones
de grupo espec\'ificas.

\subsection{An\'alisis del grupo el\'iptico y descarte de P-256 en Python}
Se analiz\'o inicialmente la posibilidad de utilizar la curva est\'andar
\textbf{NIST P-256} como alternativa de repuesto al ser de orden primo ($h=1$).
Sin embargo, se determin\'o que \textbf{P-256 no es viable en la biblioteca
\code{cryptography}} para este protocolo. La API de curvas el\'ipticas de
\code{cryptography} (\code{cryptography.hazmat.primitives.asymmetric.ec}) est\'a
dise\~nada exclusivamente para intercambio ECDH de alto nivel y firmas ECDSA;
no expone operaciones aritm\'eticas arbitrarias sobre puntos de la curva, tales
como la suma de dos puntos p\'ublicos ($u_j = u \cdot v^j$) ni la multiplicaci\'on
escalar de un punto arbitrario por un escalar independiente.

Por el contrario, la biblioteca \textbf{\code{PyNaCl}} (enlace a \code{libsodium})
expone directamente la interfaz de bajo nivel de \texttt{ristretto255} a trav\'es de
sus bindings (\code{nacl.bindings.crypto\_core\_ristretto255\_add} y
\code{nacl.bindings.crypto\_core\_ristretto255\_scalarmult}), permitiendo
ejecutar la suma de puntos y la multiplicaci\'on escalar en tiempo constante de
forma nativa, segura y eficiente.

\subsection{Versiones fijadas del ecosistema de dependencias}
Para garantizar la reproducibilidad completa del producto de software, se fijan
las versiones m\'inimas en el entorno:
\begin{itemize}
\item \code{pynacl >= 1.5.0}: Soporte nativo y probado de primitivas Ristretto255.
\item \code{cryptography >= 42.0.0}: Implementaci\'on de AES-256-GCM y HKDF con backend OpenSSL~3.
\item \code{fastapi >= 0.110.0} y \code{uvicorn >= 0.28.0}: Servidor HTTP as\'incrono de alto rendimiento.
\item \code{typer >= 0.9.0} y \code{rich >= 13.7.0}: Interfaz de l\'inea de comandos tipada con salida estructurada.
\item \code{pydantic >= 2.6.0}: Validaci\'on estricta de esquemas de datos y mensajes.
\end{itemize}
